## IF IT DOESN'T WORK

### Error: "Connection Refused"

**Check if service is running:**
```powershell
terraform output -raw ecs_cluster_name
terraform output -raw ecs_service_name

aws ecs describe-services --cluster <cluster-name> --services <service-name>
```

**Look for:** `runningCount: 2` (or more)

---

### Error: "Invalid URL"

**Get the correct URL:**
```powershell
terraform output websocket_url
```

**Make sure it:**
- Starts with `ws://` (not `http://`)
- Ends with `/ws/chat`
- Has no extra spaces

---

### Error: "Module not found: websockets"

**Install it:**
```powershell
pip install websockets
```

---

### No Response / Hanging

**Check logs:**
```powershell
terraform output -raw cloudwatch_log_group

aws logs tail <log-group-name> --follow
```

**Look for errors** in the output

## WHAT'S HAPPENING BEHIND THE SCENES

When you run the script:

```
Your Script
    ↓ (WebSocket connection)
ALB (Load Balancer)
    ↓ (routes to healthy task)
Fargate Task (your RAG service)
    ↓ (retrieves context)
Qdrant (vector database)
    ↓ (query + context sent to LLM)
EKS LLM (TheCode_ttft)
    ↓ (streams response back)
Your Script (displays streaming tokens)
```

**Total latency:** Usually 1-3 seconds to first token
