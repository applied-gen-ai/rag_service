## OVERVIEW

You have **4 Python scripts** to test your Fargate-deployed RAG service:

1. **simple_test.py** - Quick single query test
2. **advanced_test.py** - Multiple queries with detailed metrics
3. **interactive_chat.py** - Chat interface with your RAG
4. **load_test.py** - Performance/load testing

All scripts test the complete flow:
```
Client → WebSocket → Fargate → RAG → Qdrant (context) → EKS LLM → Streaming Response
```

---

### Install Dependencies

```powershell
pip install websockets
```

## GETTING YOUR WEBSOCKET URL

### Option 1: Auto-detect (Recommended)

Scripts 2-4 auto-detect from Terraform output:

```powershell
cd E:\rag_radha\rag_service\terraform
terraform output websocket_url
```

**Example output:**
```
ws://rag-streaming-production-alb-123456789.us-east-1.elb.amazonaws.com/ws/chat
```

### Option 2: Manual

If not using Terraform, get your ALB DNS name:

```powershell
aws elbv2 describe-load-balancers --names rag-streaming-production-alb --query "LoadBalancers[0].DNSName" --output text
```

Then build the WebSocket URL:
```
ws://<ALB-DNS-NAME>/ws/chat
```

## TROUBLESHOOTING

### Error: "Invalid WebSocket URL"

**Problem:** Wrong URL format or DNS name

**Solution:**
```powershell
# Get correct URL
terraform output websocket_url

# Or manually check ALB exists
aws elbv2 describe-load-balancers --names rag-streaming-production-alb
```

---

### Error: "Connection Refused"

**Problem:** Service not running or not healthy

**Solution:**
```powershell
# Check service status
aws ecs describe-services --cluster rag-streaming-production-cluster --services rag-streaming-production-service

# Check tasks are running
aws ecs list-tasks --cluster rag-streaming-production-cluster --service-name rag-streaming-production-service

# Check task health
aws ecs describe-tasks --cluster rag-streaming-production-cluster --tasks <task-id>
```

---

### Error: "Connection Timeout"

**Problem:** Security groups blocking traffic

**Solution:**
```powershell
# Check ALB security group allows port 80
aws ec2 describe-security-groups --group-ids <alb-sg-id>

# Check Fargate security group allows traffic from ALB
aws ec2 describe-security-groups --group-ids <fargate-sg-id>
```

---

### Error: "No response received"

**Problem:** Application error or crash

**Solution:**
```powershell
# Check CloudWatch logs
aws logs tail /ecs/rag-streaming-production --follow

# Look for errors in startup or request handling
```

---

### Slow Responses

**Problem:** Performance issues

**Check:**
1. **Task CPU/Memory:** May need more resources
2. **LLM Endpoint:** EKS service might be slow
3. **Qdrant:** Vector search taking too long

**Solution:**
```powershell
# Check task metrics
aws ecs describe-services --cluster rag-streaming-production-cluster --services rag-streaming-production-service

# Scale up if CPU/memory high
aws ecs update-service --cluster rag-streaming-production-cluster --service rag-streaming-production-service --desired-count 4
```

## INTEGRATION WITH CI/CD

### GitHub Actions Example

```yaml
name: Test RAG Service

on: [push]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      
      - name: Setup Python
        uses: actions/setup-python@v2
        with:
          python-version: '3.10'
      
      - name: Install dependencies
        run: pip install websockets
      
      - name: Run tests
        run: python advanced_test.py
        env:
          WEBSOCKET_URL: ${{ secrets.RAG_WEBSOCKET_URL }}
```

### Performance Benchmarks

- Success Rate: > 99%
- Response Time: < 5s

**Needs Optimization:**
- Time to First Token: > 3s
- Tokens per Second: < 50
- Success Rate: < 95%
